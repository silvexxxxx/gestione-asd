# Always Commit

When you make changes to files, you must ALWAYS run `git add`, `git commit -m "..."`, and `git push` immediately after verifying the changes, or as the last step of your turn before talking to the user.

Do not wait for the user to ask you to push. The user expects all changes to be pushed automatically.
